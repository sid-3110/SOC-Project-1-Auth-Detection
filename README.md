# SOC Project 1: Unauthorized Login Detection

## Objective
To detect brute force and password spraying attacks using
Windows and Linux authentication logs.

## Skills Demonstrated
- Windows Event Log analysis
- Linux authentication log analysis
- Brute force vs password spray detection
- SOC alert triage and escalation logic

## Tools & Concepts
- Windows Event Viewer
- Linux auth.log
- SOC investigation mindset
- Log pattern analysis

## Outcome
This project demonstrates how a SOC L1 analyst identifies
suspicious authentication behavior and decides escalation.
