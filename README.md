# SOC Project 1: Unauthorized Login Detection (Windows & Linux)

## Objective
The objective of this project is to understand how a SOC Level 1 analyst
detects unauthorized login attempts by analyzing authentication logs
from Windows and Linux systems.

This project focuses on identifying common attack techniques such as
brute force attacks and password spraying using log patterns and context.

---

## Why This Project Matters
Authentication attacks are one of the most common alerts handled by SOC teams.
Attackers often try to gain initial access by guessing passwords or abusing
weak authentication mechanisms.

Being able to correctly identify these attacks is a core responsibility
of a SOC L1 analyst.

---

## Skills Demonstrated
- Understanding SOC analyst responsibilities
- Windows Event Log analysis
- Linux authentication log analysis
- Brute force and password spray detection
- Pattern-based investigation
- Escalation vs false positive decision making

---

## Tools & Concepts Used
- Windows Event Viewer
- Linux authentication logs (/var/log/auth.log)
- SOC investigation mindset
- Log correlation and pattern analysis

---

## Outcome
This project demonstrates how a SOC analyst uses logs as evidence
to detect suspicious login behavior and reduce organizational risk
through timely escalation.
